# Ao-Oni-2016-English-Translation
Usage:

This requires that you first have a copy of Ao Oni 2016. I know nothing about the legality of obtaining one, so doing so will not be covered here.

I used version 8.4.15B of Translator++, which at the time of writing, is still actively updated, so if any of the UI has changed, the instructions below may become less helpful.

As a failsafe, you can try reading Translator++'s docs, especially their getting started page, and that may fill in the necessary blanks.


1:
Get Translator++ from https://dreamsavior.net

2:
Put the .trans file in the directory of your copy of Ao Oni 2016 which contains the game executable. This should be the root folder.

3:
Open Translator++, and select, "Open Project". Navigate where you put the .trans file, and select it.

4:
At the top of the window, click Home, (you will likely not need to do that) and then click on the syringe icon.

5:
In the window that comes up, specify what folder you want the English copy that Translator++ is going to create to be in. You should not need to mess with any other settings.

I set it to `C:/Users/USERNAME/Desktop/aooni 2016 (en)`.

6: (Final)
Wait for it to finish, then hit, "Close", and close Translator++. This has created an English language version of the game in the folder you specified in step 5. You can open that folder, and launch the game to enjoy.


Note:
There is a puzzle required for the true ending which requires you to be familiar with the Japanese abacus called a Soroban. I recommend reading about how it works before playing, and hopefully, if you recognize it in the puzzle, you will not be stuck. Otherwise, searching Ao Oni, and then the name of the item should be sufficient.


Translation notes:
- Some grammatical changes are made to JMU's original translations.
- Some changes to JMU's translation are caused by inconsistensies in redundancy of text usage. 
- The Stick has been renamed to Offertory Stick.
- In some places, although a different translation might be preferred, I have chosed to call things what the wiki presently call them.
- The translation was mostly done by using Google Translate, but almost all entries had to be reworded for space constraints, differences required by context, or voice.
- I do not speak Japanese, or have access to noprops, so some things which were unclear may not align with the original author intent.
- Some menu elements are not translated, as either Translator++ does not expose them, or they are within the javascript portions, which are not always advisable to translate.
